# Supermart Grocery Sales Dashboard

## Project Overview
This project analyzes the Supermart Grocery Sales dataset using Tableau Public. It includes sales analysis, profit analysis, regional performance, monthly trends, and business insights.

## Objectives
- Analyze total sales and profit.
- Compare sales across product categories.
- Analyze sales performance by region.
- Identify monthly sales trends.
- Present business insights and recommendations.

## Dataset
- File: Supermart Grocery Sales - Retail Analytics Dataset.csv(2).xlsx
- Total Records: 9,994
- Total Fields: 11
- Date Coverage: 2015–2018

## Dashboard Sheets
1. Sales by Category
2. Sales by Region
3. Profit by Category
4. Monthly Sales Trend

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Unique Customers
- Profit Margin

## Filters and Interactivity
The dashboard can use Order Date, Region, Category, and Sub-Category filters. Tooltips help users inspect chart values.

## Business Insights
- Compare sales across categories to identify top-performing products.
- Analyze regional performance to understand sales contributions.
- Review monthly sales trends to identify peaks and changes.
- Consider profit as well as sales when evaluating performance.
- The dataset covers Tamil Nadu, so it does not support comparisons between different states.

## Tools Used
- Tableau Public
- Microsoft Excel
- Microsoft PowerPoint

## Deliverables
- Tableau dashboard workbook (.twbx)
- PowerPoint summary (.pptx)
- README file (.txt)
- Original dataset (.xlsx)
